# Vision For Xperiences — Support

**Single-page support portal** for clients of Vision For Xperiences.

[vfx.support](https://vfx.support)

---

## Purpose

This site allows clients to submit support requests directly to the Vision For Xperiences team. Submissions are handled via Formspree and answered within 48 hours.

---

## What you can request

| Category | Description |
|---|---|
| **Project Help** | Guidance or questions on an ongoing project |
| **Technical Issue** | Problems with software, tools, or delivered assets |
| **Delivery / Files** | Help receiving or accessing deliverables |
| **Revision Request** | Changes to completed work |
| **Account / Billing** | Invoice or payment queries |

---

## Tech

Static single-page HTML/CSS/JS site -- no framework, no build step.
Form submissions handled by [Formspree](https://formspree.io).
Hosted on GitHub Pages with a custom domain.
Background video served from [vfx.productions](https://vfx.productions).
